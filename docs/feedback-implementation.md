# 현장 피드백 반영 범위

> 2026-09-28 후속 변경: 아래는 최초 피드백 반영 당시 기록입니다. 기도·사진은 이제 명시적 동의 → 서버 접수 → 슈퍼 어드민 검수 → 공개가 가능합니다. 사진은 실제 업로드 완료 기준 `오늘 사진 참여 N건`으로 집계하며 반복 참여를 허용합니다. migration005와 비공개 버킷을 적용했고 기존 운영 migration004는 여전히 보류입니다. 현재 기준은 [공개 접수 운영](community-operations.md)을 보세요.

## 공개 화면
- 사용자 제공 운영 안내: 송림학교 입장은 오전 3시부터. 학교 입장과 본당·체육관 개방은 구분한다. 시간만으로 실시간 입장 가능 상태를 자동 변경하지 않는다.
- 입장 흐름 첫 단계: 입장 전.
- 갈보리교회 주차장을 송림 선택 화면에 별도 항목으로 추가하되 실제 사용 가능 여부는 현장 확인 전으로 유지한다. 미확인 주소·개방시간은 만들지 않는다.
- 간식 나눔 명칭은 오병이어 챌린지. 월·금·토 교회 간식 배부와 별도의 1청년부 3팀 자율 나눔임을 명시한다. 피켓·바구니·쪽지 안내는 사용자가 제공한 계획이다.

## 기도·묵상
- 요청형 제목: 함께 기도해주세요.
- 기본 공개 요청은 미반영: 기도제목은 제3자 건강·가족 사정 등의 민감정보를 포함할 수 있으므로 비공유 기본과 명시적 동의를 유지한다.
- 동의 후 미리보기의 별도 공유 버튼을 눌러 기기 공유 메뉴에서 앱과 받는 사람을 선택한다. 서버 접수 또는 공개 게시판 등록이 아니다. 공유 메뉴의 완료를 메시지 전달 성공으로 표현하지 않는다.
- 특새 묵상은 날짜별 작성, 텍스트 파일 다운로드와 명시적 동의 후 공유. 입력 본문은 브라우저 메모리에만 있고 새로고침 시 사라진다. 자동 서버 업로드나 본문 localStorage 저장은 없다.

## 사진
- 폴라로이드 메모, 이미지 저장·기기 공유, 날짜별 내 기기 기록.
- 사진과 메모를 서버에 업로드하지 않는다. 기기 날짜 기록은 사진 인증·출석이나 인원 집계가 아니다.
- 전체 사진 인증 인원 수는 구현하지 않는다. 접수 서버·동의·검수·중복 판정 및 보관 정책 없이는 실제 인원 수를 계산할 수 없다.

## 운영 연결 제한
최종 배포 검증에서 이전과 달리 v2 운영 API가 enabled:true와 실제 현황을 반환함을 확인했다. v1과 v2의 전체 자원 ID·버전·갱신시각이 일치하며, Supabase에는 teuksae-hyeonjangpan 프로젝트가 있다. 공유 운영 DB일 가능성이 높아 기존 v1에 영향을 줄 수 있는 마이그레이션004는 실행하지 않았다. 현재 응답에는 occupancyPercent/lastClosedAt/parking.calvary가 없으므로 새 스키마가 아직 활성화되지 않았다. 기존 상태 저장은 구형 RPC와 호환하고, 사용률 입력은 새 스키마가 확인될 때만 표시한다. 비율·마감 이력 실운영은 공유 DB 대상·v1 영향 확인 및 마이그레이션 적용이 필요한 보류 항목이다. 공개 기도·사진 접수와 전체 집계 역시 별도 서버 및 운영 정책 결정이 필요하다.
