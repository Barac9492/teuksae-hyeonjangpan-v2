# 송림 예배공간·대기줄 시각화 근거

조사일: 2026-09-14. 설계 참고용이며 실측도·실시간 현황이 아니다. 이 근거를 바탕으로 VenueIllustration 컴포넌트를 로컬 구현했다. 본당 장의자·체육관 접이식 의자 추상 구역도와 기준점 대기줄 시안이다. 드림센터·온라인에는 좌석도를 추가하지 않는다. 전체 테스트 71개, 빌드·린트, 독립 정적 리뷰 통과. 320px/390px iframe 검수(스크롤바 제외 실제 305px/375px)에서 가로 넘침 없음, 구역 버튼 최소 높이 142px, 셀렉트 46px/16px 확인. 게시 승인 전이며 실시간 운영 입력은 구현 범위가 아니다.

## 대기줄

사용자가 현장 동선을 직접 확인: **송림고등학교 입구 → 동명유치원 → 분당카병원 → CU** 순서의 길에서 대기한다. 일반 이매역 길찾기 결과를 대기줄로 대체하지 않는다.

확인한 주소:
- 송림고등학교: 이매로 100. 학교 공식 https://songlim-h.goesn.kr/songlim-h/lm/location/locationMapView.do?mi=13990
- 동명유치원: 이매로 88. https://www.daycarekorea.com/child/kinder_detail.php?name=%EB%8F%99%EB%AA%85%EC%9C%A0%EC%B9%98%EC%9B%90&addcode=41135106
- 분당카병원: 이매로 84. 네이버 지도 상세 직접 확인 https://pcmap.place.naver.com/place/37430097
- CU 분당이매역점: 이매로 80. 네이버 지도 상세 직접 확인 https://pcmap.place.naver.com/place/31020831

네이버 일반 길찾기에서 정문→이매역 3번 출구는 288m로 표시되었지만 이는 대기줄 길이가 아니다. 특히 동명유치원 부근 횡단보도를 포함한 일반 경로를 실제 줄에 그대로 적용하면 안 된다. 건물 기준점 순서는 사용자의 현장 확인을 근거로 확정하고, 보도의 세부 굴곡·횡단 여부·실측 거리·유효 폭은 미확인으로 남긴다.

시각화: 입구부터 줄 끝까지 채워지는 경로와 4개 기준점. CU가 고정 최대 길이라는 의미는 아님. 끝점 상태는 입구 부근/동명유치원 부근/분당카병원 부근/CU 부근/그 너머/확인 중 등을 지원할 수 있다. 실제 인원수·대기시간·이동 애니메이션을 만들지 않는다. 예시 모드에서는 끝점과 시간 모두 예시 표기. 운영 시 담당자가 끝점을 선택하고 오래된 값은 확인 중으로 만료.

## 본당

공식 사진에서 고정식 긴 나무 장의자, 강단 방향으로 이어지는 통로, 측면 높은 좌석 공간을 확인했다. 직사각형 강당, 한쪽 짧은 벽에 강단과 스크린. 완전한 발코니 형태·정확한 좌석 블록 수·출입문 운영 배정은 미확인.

단순한 3×3 임의 구획을 실측 좌석도처럼 제시하지 말 것. 개별 점을 실제 좌석 수로 해석하게 하지 말 것. 장의자 줄무늬와 통로를 추상적으로 표현하고, 혼잡도는 구역 단위로만 표시한다.

## 체육관

공식 사진에서 녹색 바닥, 단상/스크린, 여러 블록으로 배치된 접이식 의자, 블록 사이와 주변 통로를 확인했다. 본당과 구별되는 임시 배치. 양측 높은 난간 공간은 보이지만 예배 좌석으로 사용되는지는 확인되지 않았다. 행사마다 배치가 달라질 수 있으므로 정확한 행/열/통로 수를 고정하지 않는다.

## 운영 흐름 정정 (동일 날짜, 사용자 현장 방침)

- 본당 개방 전: 체육관 먼저 개방. 본당에서 예배드리려는 분만 대기한다.
- 본당 개방 후: 본당 대기줄은 사라진다. 대기줄 약도/선택기를 제거하고 본당 구역도만 표시한다. 본당 구역도와 대기줄의 동시 표시는 금지한다.
- 개방 단계는 이 시안의 로컬 체험용 토글이며 실제 개방을 제어하지 않는다. 개방 시각은 미정. 개방 여부와 혼잡도는 별도 상태로 취급한다.
