## 사용 흐름

별도 검토에서 **자동 가림 / 직접 수정**을 선택한다. 작성 원문은 읽기 전용이며 직접 수정은 별도 공개 문구만 편집한다. 자동 가림은 기존 10개 정확 문자열 정책을 그대로 사용한다. 직접 수정 문구에도 지정 표현이 남으면 게시할 수 없다. 어떤 모드든 공개 미리보기 확인 → 서버가 확인한 정확 문구 표시 → 확인 후 공개 문구 게시를 거친다. 기존 일반 승인·일괄 승인으로 우회할 수 없다.

모드 전환과 확인 취소는 이 화면의 수동 초안을 보존한다. 확인 중에는 입력과 모드 변경을 잠근다. 초안은 메모리에만 있으며 목록 새로고침·탭 이동 시 저장되지 않는다는 안내를 표시한다. 브라우저 페이지 이탈에는 변경된 초안의 beforeunload 경고를 요청한다(브라우저 지원에 따름). 저장/임시저장 기능은 추가하지 않았다.

작성 안내:
> 어린이도 함께 보는 공간입니다. 관리자가 확인한 뒤 일부 표현을 **로 가리거나 공개 문구를 수정할 수 있습니다. 작성 원문은 보관됩니다.

## 서버·SQL 경계

- 기존 최고 관리자 세션을 HTTP와 SQL에서 재검증한다. 기존 계정/세션/게시물 잠금 순서를 유지한다.
- 미리보기는 원문 SHA-256, 행 버전, 정책 버전, 모드, 정확 공개 문구를 검증한다. 원문은 브라우저 관리자 화면에만 기존 권한으로 제공하며 원문 해시는 접근 토큰이 아니다.
- HTTP는 미리보기 필드와 세션 ID를 HMAC으로 묶어 10분간 유효한 확인 토큰을 발급한다. 확정 때 변조·다른 세션·만료를 거부한다. SQL은 잠금 안에서 원문 해시·버전·정책·문구를 다시 검증한다. 미리보기 호출은 게시물/감사기록을 쓰지 않는다.
- 문구는 1~600 Unicode 코드 포인트이며 공백만 있는 문구를 거부한다. JS와 SQL은 ECMAScript 공백 집합을 포함해 검사한다. 문구를 trim/정규화하거나 자동 재작성하지 않는다. UI maxLength 1200은 UTF-16 보호 한계이며 실제 600자 제한은 코드 포인트로 별도 검증한다.
- 자동 모드는 정확한 결정적 치환과 일치해야 한다. 수동 모드는 지정 표현이 없어야 한다. 같은 버전으로 재확정하면 충돌하며 감사기록은 중복되지 않는다.
- 공개 옛 목록·페이지 RPC는 기존 `masked_public_text`를 두 모드의 검토된 공개 문자열로 사용한다. HTTP 허용 필드 목록을 유지하여 원문/해시/초안/검토 메타데이터를 제거한다. 작성자 상태 조회·삭제 토큰·동의·접수 해시 계약은 유지한다.
- 휴지통/복원/철회/기존 삭제는 공개 문구와 모드도 초기화한다. 기존 가림 승인과 수동 게시 모두 정책/원문 변경 시 재검토한다. 운영 자료를 읽거나 실제 게시 결정을 내리지 않았다.
