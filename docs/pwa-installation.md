# 홈 화면 설치 안내

예배 첫 화면 상단의 설치 카드에서 설치할 수 있다. Android/데스크톱의 지원 브라우저에서는 beforeinstallprompt를 보관했다가 사용자의 버튼 클릭으로만 연다. 이벤트는1회용이며 취소 뒤에는 수동 안내로 전환한다. iPhone/iPad에는 Safari 공유 → 홈 화면에 추가 → 추가 절차를 안내한다. 아직 실제 설치 확인이 없는 단순 설치 동의/설명 열기를 설치 완료라고 기록하지 않는다.

설치 완료(appinstalled) 또는 standalone/navigator.standalone 실행이 확인되면 이 기기에 설치 표시를 저장하고 안내를 숨긴다. 브라우저가 다시 설치 가능 이벤트를 보내면 이전 표시를 지워 재설치를 허용한다. 일반 브라우저 전체화면은 설치 증거로 보지 않는다. 닫기는 현재 탭 세션 동안만 유지한다. 로컬 저장소가 차단돼도 화면과 설치 설명은 사용할 수 있다.

**제약:** 모든 브라우저에서 이미 설치한 앱을 일반 탭에서 완벽하게 판별할 수는 없다. 특히 iOS에서는 설치된 앱으로 실행했을 때 확실히 숨길 수 있지만 Safari와 설치 앱의 저장소가 공유되지 않을 수 있다. 설치되지 않은 사람만100%판별한다는 보장은 하지 않는다.

manifest는 루트 범위/standalone,192·512PNG아이콘과180Apple아이콘을 사용한다. 루트 앱에서도 서비스워커를 등록한다. API와 관리자 요청은 서비스워커가 저장하지 않으며, 오류 응답이나 JS 대신 온 HTML도 자산 캐시에 저장하지 않는다. 기기 알람·실시간 오프라인 현황 지원을 뜻하지 않는다.
