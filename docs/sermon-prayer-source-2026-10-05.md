# 첫날 묵상 질문 원문 교정

## 교정 범위

사용자가 배포된 ‘오늘의 묵상 질문’을 오늘 말씀에서 직접 가져오도록 요청했다. PR31 운영 main `0130927d1b9ceb182dd4d6935ea4c29f940a9cf5`를 원격에서 다시 확인하고 분기했다.

기존 창작질문 두 개를 앱 데이터에서 모두 제거했다. 질문을 새로 만들거나 원문에 물음표를 붙이지 않았다. 접기 섹션명은 ‘말씀에서 나눈 기도 제목’이며, `sermons.ts`의 `prayerExcerpt`에는 실제 자막의 연속된 기도 권면 한 문장만 있다. 38:46–38:54 구간으로 이동하는 링크를 함께 표시한다. 첫날 제목·핵심·버튼·타이머·작성/동의 보존과 다른 날짜는 그대로 유지한다. API·DB 변경 없음.

## 원근거와 검증 수준

- 공식 영상: https://www.youtube.com/watch?v=0e11fIrc_6s
- 영상 제목: 다윗의 중심 | 이찬수 목사 | 분당우리교회 가을특별새벽부흥회 | 2026-10-05
- 채널: 분당우리교회 (`@BundangWooriChurch`), 영상 페이지에서 확인.
- 인용 구간: https://www.youtube.com/watch?v=0e11fIrc_6s&t=2326s
- 공개 영상의 한국어 **자동 생성 자막**을 브라우저 transcript export로 확보했다. 해당 연속 자막 행의 시작은 38:46 / 38:49 / 38:52이고 다음 발화 행은 38:54이다.
- 38:50 화면 자막에서 인용 시작 부분을, 38:55 화면 자막에서 직전 종결 표현을 대조했다. 내보낸 자막과 화면 자막이 일치했다.
- **직접 오디오 청취 검증을 수행한 것으로 주장하지 않는다.** 동일 자동자막의 export와 플레이어 표시를 대조한 수준이다. 선택 구절에 추측 교정이나 추가 어구는 없다. 다른 구간에서 보이는 자막 오류를 추정해 바로잡거나 인용하지 않았다.
- 질문 문장이 아니라 영상의 기도 권면이므로 질문 형식으로 바꾸지 않았다. 긴 전사나 영상·오디오 파일은 저장소에 추가하지 않는다.

## 검증

기존 창작질문 부재, 새 섹션·원구간 링크, 기본 접힘과 펼침을 단위·브라우저 회귀 검사에 포함했다. 타이머·작성·동의·취소·뒤로/앞으로 회귀는 기존 검사로 유지한다. 전체 CI에서 최종 후보 SHA를 확인하고 병합 후 production READY와 정적 UI만 검사한다. 운영 검증은 API 조회를 빈 응답으로 대체하고 모든 쓰기를 차단한다.
