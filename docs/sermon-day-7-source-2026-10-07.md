## 앱 항목별 근거

| 필드 | 앱 값 | 자동자막 타임스탬프와 행 |
|---|---|---|
| `title` | `골리앗보다 크신 하나님을 보라` | 영상 제목과 설명의 `제목` |
| `passage` | `사무엘상 17:31–37` | 영상 설명의 `본문 : 사무엘상 17장 31-37절` |
| `reflectionTitle` | `기름부으심이 가져다 준 세 가지 변화` | 자동자막 `[18:09 - 18:14] 기름부심이 가져다 준 세 가지 변화`; Ethan이 `기름부으심`으로 직접 교정 |
| `points[0]` | `보는 눈과 언어가 달라집니다.` | `[37:54 - 38:01] 기름부음 받은 자는 첫째 보는 눈과` + `[37:58 - 38:04] 언어가 달라집니다. 둘째 기름부음` |
| `points[1]` | `사람의 평가에 연연하지 않습니다. 끌려다니지 않습니다.` | `[38:01 - 38:07] 받은 자는 사람의 평가에 연연하지` + `[38:04 - 38:10] 않습니다. 끌려다니지 않습니다. 셋째` |
| `points[2]` | `과거의 은혜로 현재를 재해석합니다.` | 자동자막 `[38:07 - 38:13] 기름부음 받은 자는 과거의 은혜로` + `[38:10 - 38:15] 현재를 재해석갑니다.`; Ethan이 `재해석합니다`로 직접 교정 |
| `prayerExcerpt.text` | `우리의 눈을 열어 주님을 보게 하여 주옵소서.` | `[44:48 - 44:53] 인도하여 주옵소서. 우리의 눈을 열어` + `[44:51 - 44:55] 주님을 보게 하여 주옵소서. 하나님` |
| `prayerExcerpt.startSeconds` | `2688` | 문장 첫 단어 `우리의`가 포함된 첫 자막 행의 시작 `44:48` |
| `prayerExcerpt.timeLabel` | `44:48–44:55` | 문장을 포함하는 두 자막 행의 전체 범위 |

설교자는 `[37:52 - 37:58] 이 세 가지 기억하셔야 됩니다.`라고 말한 뒤 첫째·둘째·셋째를 연속으로 다시 열거한다. 앱의 세 `points`는 그 결론 구간에서 각 번호와 공통 주어를 제외한 핵심 문장을 그대로 옮겼다.

기도 발췌는 앞 문장이 `[44:48 - 44:53]` 행 안의 `주옵소서.`에서 끝난 직후 시작하고, 다음 행에서 `주옵소서.`로 끝나는 한 문장이다. 서로 떨어진 문장을 이어 붙이지 않았다.

## 검증 수준과 불확실성

- **한국어 자동자막 텍스트만 검증했다. 직접 음성을 듣고 대조하지 않았다.**
- 자동자막의 `기름부심`과 `재해석갑니다`는 Ethan의 직접 교정에 따라 각각 `기름부으심`과 `재해석합니다`로 바로잡았다.
- `reflectionTitle`에는 설교자가 세 항목을 소개할 때 사용한 프레이밍 문구를 썼고, `points`에는 결론에서 명시적으로 다시 열거한 세 문장을 썼다.
- 10월 5일과 6일 데이터는 변경하지 않는다. UI·API·DB·migration 변경도 없다.
- 이 변경은 Ethan의 문구 승인 전에는 병합하거나 배포하지 않는다.
