# 마지막 운영 현황 유지

10분이 지나도 마지막 입력값을 계속 보여주고 마지막 확인 시각을 함께 표시해 달라는 승인에 따라 공개 운영 현황의 만료 정책을 변경했습니다. 이 정책은 앞선 출입 일관성 보고서의 10분 후 값 숨김 설명을 대체합니다.

- 학교/입장 단계, 본당·체육관·드림센터 사용률, 송림 주차와 드림센터 안내 층 모두 마지막 저장값을 유지합니다. 오래된 값은 회색으로 표시하고 ‘마지막 기록’을 덧붙여 최근 확인과 구분합니다. 명시적으로 저장된 확인 전·닫힘·입장 마감·만차를 다른 값으로 만들어내지 않습니다.
- 마지막 확인 시각은 한국 시간입니다. 이전 날짜이면 월·일, 이전 연도이면 연도까지 표시합니다. 자정을 막 넘긴 2분 전 기록도 오늘 확인한 값처럼 표시하지 않습니다. 시각이 없거나 비정상·미래이면 확인 필요입니다.
- 연결 실패·오프라인에서는 이미 불러온 운영값을 유지하고 ‘연결 확인 중’을 표시합니다. 새로 접속한 오프라인 기기에 저장 기록을 만들어내지 않습니다. 값은 메모리에서 유지하며 새 로컬 영구 저장소는 추가하지 않습니다.
- 자정이나 예배 시간 경계에서 이미 받은 운영 스냅샷을 삭제하지 않습니다. 기존 요청 취소와 늦은 응답 무시 검사는 유지합니다. 예배 중(10월5–10일 04:40–05:50)에는 상태값 대신 ‘예배 중’, 05:50 이후 HOME 공간 영역에는 귀가 안내를 표시하는 정책은 유지합니다. 주차는 재개하며 새 조회가 실패하면 마지막 기록과 연결 경고를 표시합니다.
- 입장 흐름의 ‘현재 단계’ 강조는 최근 확인에만 사용하며, 오래된 입장 단계 값 자체는 상태 행에서 계속 볼 수 있습니다.
- 관리자 공개 상태·운영 안내도 ‘마지막 기록 표시 중’으로 일치시켰습니다. 오래된 값을 현장 재확인 없이 새 시각으로 덮어쓰지 않도록 하는 기존 명시적 재선택 규칙과 저장 전 입장 충돌 경고는 유지합니다.

## 검증

- `npm test`: 54개 파일, 604개 테스트 통과. 새 23개 테스트는 10분 직전/정각/직후, 1시간/7일 경과, 모든 입장 단계와 명시 상태, 비정상 시각, 날짜·연도 경계, managed/unmanaged 런타임의 오프라인·실패·재연결·예배 전환을 확인합니다.
- `npm run build`, `npm run lint` 통과. 서버는 변경하지 않았고 서버 회귀 테스트도 별도 실행했습니다.
- `tests/scripts/entrance-browser.mjs`: 320/390/1440px에서 운영값 유지·날짜·오프라인/실패/재연결·경고·예배 시간 전환·가로 넘침을 확인했습니다. localhost 외 통신을 차단하고 API를 합성 응답으로 처리했습니다. 운영 쓰기는 없습니다.

## 반영 범위

이 커밋은 출입 수정 `19529c77` 위의 추가분입니다. 운영 UI·운영 상태 런타임·해당 테스트/설명만 변경합니다. 기도 편집/공개 API나 DB 마이그레이션은 없습니다. 배포 담당자는 기존 출입 커밋에 이 추가 커밋을 반영하면 됩니다. 운영 DB 값으로 검증하지 않습니다.
