# 특새 현장판 — 조사 결과 및 제품 계획

작성 기준일: 2026-08-24

## 0. 결론

또 하나의 묵상·출석 앱은 만들지 않는다. 이미 홈페이지, 유튜브, 카카오톡, 가이드북, 스티커, 동판이 그 역할을 잘한다. 만들 가치가 확인된 것은 교회 공식 **"특새 현장판" 모바일 웹**이며, 개인 기록과 특새 이후 실천(일새)을 아주 얇게 붙인다.

## 1. 조사 범위

- 공개 접근 가능한 공식 게시판 글 867건, 댓글 1,488건
- 기간: 2003년 9월 ~ 2025년 12월, 본문 약 110만 자
- 짧거나 이미지 중심인 글 29건은 별도 시각 판독 (실제 이미지 19건 확인, 2008년 외부 이미지 3건은 원본 서버 소실로 판독 불가)
- 중복 글·설교 전문·공식 기도제목·개인 체험을 구분해 분석
- **바이어스 주의:** 자발적 후기 작성자 표본이라 긍정적·강한 체험이 과대표집됐을 가능성

## 3. 후기 전체에서 드러난 특새의 본질

1. **특새는 콘텐츠가 아니라 몸으로 건너가는 순례다.** 새벽 1~3시 출발, 줄서기, 가족 깨우기, 카풀, 간식, 출근 버티기. 불편 자체를 은혜로 해석하는 문화. 단, 안전 문제는 실재한다 (2025년: 1:30 출발 → 1:55 줄서기 → 장거리 외근 운전).
2. **다락방은 신앙 공동체이자 비공식 운영망이다.** 카풀·기상 확인·자리 정보·문 개방·중보가 모두 다락방 카톡에서 이뤄진다. 2025년에는 새벽 2시부터 "여기 자리 있어요", "정문 아직 안 열렸어요" 생중계. → **가장 명백한 미충족 수요는 신뢰할 수 있는 현장 정보다.**
3. **본당을 상위 등급으로 만들면 안 된다.** 드림센터는 아이 동반 부담이 적고 예배 열기도 본당 못지않다는 후기 명확. "본당 입성 성공"을 암시하면 줄서기·장소 서열을 강화한다.
4. **동판·스티커·음식은 상품이 아니라 가족 기억이다.** 종이 가이드북과 손 필사는 예배 행위다. 디지털 동판·출석 점수로 대체하면 안 된다.
5. **온라인은 열등한 대체품이 아니다.** 입원·간병·출산·장애 자녀 돌봄·비신자 배우자·해외 거주자의 유일한 참여 수단 (2020년 암 수술 병실에서 이어폰 참여 기록).
6. **특새의 목표는 완주가 아니라 "일새"다.** 2004~2025년 "특새에서 일새로" 반복. 구조 없는 결단은 보름 만에 무너진 기록. 지속 모델: 집중 경험 → 결단 → 일상 마찰 → 구조가 있으면 부분 지속 → 없으면 약화 → 다음 특새에서 재시작.
7. **공개 기도·간증 피드는 위험하다.** 자녀 입시·장애·암 수술·배우자의 종교 거부 등 민감 정보가 실명과 함께 존재. 개인 기록은 기본 비공개·계정 없음·기기 내 저장.

## 4. 제품 정의

> 성도가 현장과 온라인 중 자신에게 맞는 예배 자리로 안전하게 도착하고, 그날 붙든 말씀을 일상으로 가져가게 돕는 교회 공식 모바일 현장판.

카카오톡·홈페이지 링크로 바로 열리는 모바일 웹/PWA.

### MVP 1: 공식 특새 현장판

성도 화면 예시:

```
03:47 공식 확인
송림 본당: 입장 마감
드림센터: 지금 권장, 아이 동반 적합
체육관: 입장 가능
송림 주차: 혼잡, 평일 6:45까지 출차
온라인 예배 바로가기
```

필수 기능:
- 장소별 공식 상태 (6종): 준비 중 / 입장 가능 / 현재 권장 / 혼잡 / 입장 마감 / 확인 중
- 이동·안전 정보: 문 개방, 주차·출차 제한, 아이 동반·자모실, 장애인·고령자 동선, 중간 출차 적합 장소
- 온라인 예배 링크 (현장과 동일한 시각적 무게)
- 신뢰 표시: 마지막 갱신 시각, 공식 담당자 확인, 일정 시간 후 자동 "확인 중" 전환

넣지 않는 것: 정확한 좌석 숫자, 사용자 제보형 혼잡 지도 (잘못된 숫자가 군중 이동을 만든다).

운영자 화면:
- 장소별 담당자가 버튼 한 번으로 상태 변경, 1회 갱신 30초 이내
- 자유문보다 정해진 상태 중심, 모든 변경에 시각·담당자 기록
- 오래된 "권장·입장 가능" 상태 자동 만료

**핵심 제품은 화면이 아니라 현장 변화를 3분 안에 공식 갱신하는 운영 프로토콜이다.**

### MVP 1.5: 비공개 개인 기록 (현장판 안정화 후에만)

- 오늘 붙든 한 문장 / 오늘 할 한 행동
- 서버 전송 없음, 6일 뒤 한 장으로 내보내기
- 종이 가이드북·필사를 대체하지 않고 보조

### Phase 2: "특새에서 일새로"

마지막 날 세 가지를 정하게 한다: 언제 / 어디서 / 누구와.
새 콘텐츠 없이 교회의 기존 한 구절 묵상·새벽예배로 연결. 공개 연속참여 점수 대신 14일 개인 체크와 회고만.

## 5. 만들지 말아야 할 것

- 별도 설교 플레이어·AI 설교 요약
- 별도 푸시 알림
- 종이 가이드북·필사노트 대체
- QR 출석, 연속참여 점수, 리더보드
- 공개 기도·간증 피드
- 정확한 좌석 숫자
- 오픈 카풀 매칭 (다락방 카톡용 문장 도우미는 매칭이 아니므로 허용)
- 가족 사진·프로필 SNS
- 본당 참여를 상위 등급으로 표현하는 모든 장치

말씀 필사·한 문장 결단·성경 퀴즈 같은 가벼운 이벤트는 과거 공식 운영에도 있었다. 보상은 출석 경쟁이 아니라 말씀을 다시 쓰고 적용하게 하는 방향이어야 한다.

## 6. 2026년 검증 계획

2026-08-24 기준 공식 특새 공지 미확인 (최근 새벽기도회는 "풍요로움의 역설" 시리즈). 공지가 행사 약 8일 전에 나온 사례가 있으므로 **날짜·테마를 코드에 박지 않는다.**

### 1주차: 협업·수요 검증

대상: 최근 참여자 20명, 다락방장 5명, 현장 봉사자 5명.

인터뷰 질문:
1. 출발 전에 어느 장소로 갈지 어떻게 정하셨나요? (본당 고집 여부, 정보 출처)
2. 새벽에 카톡·전화로 상황을 몇 번이나 물어보셨나요? 누구에게?
3. 잘못 간 장소, 차 돌린 경험, 재이동이 있었나요? 그때 무엇을 알았다면 달라졌을까요?
4. 아이 동반·거동 배려·중간 출차 때문에 꼭 필요했던 정보는 무엇이었나요?
5. "03:47 공식 확인, 드림센터 지금 권장"이 화면에 떠 있었다면 실제 행동이 달라졌을까요? (데모 화면 제시)

### 2단계: 개발 없는 모의운영

- 링크 한 장(이 레포의 데모)과 운영자 단톡방만 사용
- 세 장소 상태를 가상으로 변경, 담당자가 실제 새벽 상황에서 갱신 가능한지 확인
- 일반 새벽기도회 하루에 실전 리허설

### 3단계: 통과할 때만 구축

- 5일 이내 PWA 구축 → 특새 1~2일차 제한 파일럿 → 데이터가 정확할 때만 전체 배포

### 성공 기준

- 실제 변화 후 3분 이내 갱신 95%
- 잘못된 "권장·입장 가능" 상태 5분 이상 유지 0건
- 이용자 60% 이상 "장소 선택 불확실성 감소" 응답
- 반복 문의·차량 재이동·잘못 온 방문 30% 이상 감소 (비교일 대비)
- 운영자 갱신 30초 이하
- 개인정보 사고 0건

### 중단 기준 (하나라도 해당하면 올해는 만들지 않는다)

- 교회가 공식 담당자와 배포 채널을 지정하지 않음
- 참여자 30% 미만만 현장 정보 문제를 실제로 경험
- 모의운영의 오류·지연이 10% 초과
- 담당자가 집회 중 상태를 갱신할 수 없음
- 제품 가치가 결국 영상·가이드북 보기로 축소됨

## 7. 첫 결정점

교회 운영팀이 장소별 상태를 공식 제공하고 갱신할 수 있는가.
가능하면 "특새 현장판"을 만든다. 불가능하면 범용 묵상 앱으로 후퇴하지 말고 프로젝트를 중단한다.
