# 오픈 전 피드백 반영

## 변경
- 2026-10-05 00:00 KST 전 예배·주차 현황은 안내문으로 대체. 행사 기간 밖 운영 업데이트와 주차 이력은 공개 API에서 제외한다.
- 행사 기간 밖 생성된 공개 나눔 기록은 목록 및 직접 사진 URL에서 제외한다. 사진 참여 수는 행사 전 0으로 반환하고 화면은 시작 안내를 표시한다.
- 이것은 공개 노출 초기화이며 DB 삭제가 아니다. 기존 앱과 공유하는 운영 DB 및 감사 이력은 유지한다. 관리자 검수는 리허설 기록을 계속 확인할 수 있다.
- 행사 전 공개 접수 버튼은 비활성화한다. 기기 내 작성/미리보기는 가능하다.
- 중복 확인 필요 문구 제거. 사용률·주차 기록·사진 집계 설명과 동의 상세는 접어서 제공한다.
- 로컬 이야기는 나만 보는 메모로 변경한다. 묵상은 날짜별 localStorage 자동저장, 실패 알림 및 기기 공유/저장소 삭제 안내를 제공한다.
- 갈보리교회는 별도 주차 안내 구역이며 예배 장소 선택지가 아니라는 설명을 추가한다. 실제 제휴/주소/개방시간을 추측하지 않는다.

## 미해결 운영정보
오병이어 학교 밖 정확한 장소·시작/종료 시각, 예배 종료 시각은 주최 측 확인 필요. 미확정 문구를 확인 대기 안내로 정리했을 뿐, 확정된 것으로 처리하지 않았다.
공식 2026 안내 확인: https://www.woorichurch.org/modu/s_board/read.asp?board_seq=10&board_sub_seq=3&seq=428014
해당 안내는 04:40 시작, 03:50 전후 송림본당/드림센터 개방 등을 알리지만 예배 종료나 오병이어 세부 정보는 제공하지 않는다.

## 검증
- 프런트엔드 190/190, 서버 52/52, lint/build 통과.
- 별도 코드 검토에서 발견한 확인 배너 freshness 문제와 주차 이력 누락 수정.
- 독립 서버 검토 통과. 운영 DB 삭제나 실제 배포는 포함하지 않음.
- 로컬 브라우저에서 묵상 입력 후 전체 새로고침 및 재진입 시 복원 확인. 검증용 문장은 비운 뒤 확인.

## 배포 경계
v2 저장소만 변경. v1 배포 및 공유 DB 스키마를 변경하지 않는다. 공개 배포 후 예배/주차/사진 화면 및 API의 전행사 기록 배제를 재검증한다.

## 2026-09-29 사전 개방 변경
뉴스레터 사용 안내와 사전 점검을 위해 주차·예배 공간 화면을 행사 전에도 공개한다. 행사 전 값에는 ‘사전 점검 중’ 표시를 붙이고 실제 특새 운영 현황과 구분한다. 미입력·10분 경과·연결 실패 정보는 여전히 확인 필요로 표시하며, 10월 5일에는 그 이전 점검값을 실제 운영값으로 이어받지 않는다.
기도·묵상·사진은 사전 작성과 공개 접수를 허용한다. 9월 29일 이후 접수분부터 공개 목록/사진 대상이 되며, 공개 동의와 관리자 검수는 그대로 유지한다. 9월 28일까지의 리허설 기록은 계속 숨긴다. 실제 접수나 현장값을 자동 생성하지 않는다. 나눔 탭의 ‘나만 보는 메모’는 여전히 기기 내 메모이며 공개 게시 기능이 아니다.
