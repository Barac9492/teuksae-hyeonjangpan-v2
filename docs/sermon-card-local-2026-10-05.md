## 구현

기존 예배 탭의 여섯 날짜를 말씀 선택 버튼으로 연결했다. 현재 확인된 첫날을 기본 선택하고 행사 종료 후에도 찾을 수 있다. 등록된 날짜에는 ‘말씀’을 표시한다. 미등록 날짜는 미등록 안내만 보여주며 설교 제목·질문·영상·기도 행동을 만들지 않는다. 한국 날짜 기준으로 미래의 데이터도 노출하지 않는다.

카드는 공식 안내 및 입장 현황 다음, 기상 시간 계산기 전에 위치한다. 처음에는 제목과 핵심 두 가지, 접힌 질문을 보여준다. 주차 바로가기와 현장 안내의 기존 순서를 유지한다. 새 탭은 추가하지 않았다.

- 말씀 묵상: ‘하나님이 보시는 중심’
- 핵심: ‘하나님을 사랑하는 마음’, ‘하나님을 신뢰하는 마음’
- 질문: 하나님께 먼저 여쭙고 싶은 일 / 학교·집·일터에서 사랑하고 신뢰하는 마음으로 할 작은 일
- ‘이 말씀으로 1분 기도하기’: 기존 기도 타이머를 표시하고 사용자가 시작한다. 초기 기본값은 1분이며 기존 선택 시간·진행·일시정지·완료 상태를 덮어쓰지 않는다.
- ‘내 기도제목 적기’: 기존 작성 화면을 열고 입력란으로 초점을 옮긴다. 문구 자동 입력이나 자동 제출은 없다.
- ‘설교 다시 듣기’: 전달받은 원영상으로 새 창 이동.

같은 기도 패널/타이머/공개 접수 컴포넌트를 계속 유지한다. 작성 내용과 공개 동의 상태는 탭 전환, 미리보기 취소, 말씀으로 복귀, 브라우저 뒤로/앞으로, 재진입에도 유지한다. 미리보기를 연 상태에서 브라우저 뒤로가기를 누르면 모달도 닫는다. 기존 공개 버튼·검토 절차는 변경하지 않았다.

보존 범위는 현재 앱 세션이다. 기존과 마찬가지로 페이지 새로고침/앱 종료 시 타이머와 미제출 작성 내용의 영속 저장은 제공하지 않는다. 개인 내용을 localStorage나 DB에 추가 저장하지 않았다.
